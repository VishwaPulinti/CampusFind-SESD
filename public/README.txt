CAMPUSFIND — LOGIN FIRST + ITEM PHOTO UPLOAD + SAMPLE ITEM PHOTOS

RUN
1. Extract this ZIP.
2. Open the CampusFind_Login_First folder in VS Code.
3. Open index.html using Live Server or a browser.
4. Register a demo account, then log in.

ITEM PHOTOS
- Preloaded sample items now have representative item photos in their cards and detail view.
- New Lost and Found reports require at least one uploaded photo.
- Multiple photos can be selected; JPG, PNG, WEBP and GIF are accepted.
- Maximum size is 5 MB per image.
- The sample item photos are loaded from Unsplash, so internet access is needed to display them.
- Photos uploaded by a user are stored in browser-based app data in this standalone demo.

NOTE
This is a standalone HTML demo. It does not persist data to MongoDB or provide secure production authentication.
